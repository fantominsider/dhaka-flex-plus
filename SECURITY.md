# Security policy

**Status:** early source-only preview; no security support or hardened production release guarantee.

Never post access tokens, IPTV subscription URLs, additional private server addresses, signing keys or raw backups in public issues. Four documented factory RFC1918 host IPs are included intentionally in source, but are not credentials. Redact logs.

For private reports, use GitHub's private vulnerability reporting if the repository owner enables it. Otherwise contact the maintainer through a nonpublic channel established by the maintainer. Do not disclose a working exploit or credentials in a public issue.

Network access is user-configured and cleartext HTTP is possible; use trusted networks and content sources you are authorized to access.
