# Dhaka Flex Plus

Open-source Android media browser with embedded LibVLC for phones, tablets, Android TV, and experimental XR viewing.

**Status:** v0.6.1 source release candidate. The Android APK has not yet been compiled or verified on devices.

## Features
- Editable media-server catalog with four optional local-network Dhaka Flex presets
- Restore Default IP, Save IP, and Make Default controls
- HTTP(S) directory browsing, favorites, watch history, sorting and backups
- LibVLC playback, IPTV/M3U import and network stream URLs
- Experimental VR cinema, VR180/VR360 and XREAL-compatible SBS output

This is an independent, community-developed app. It is not affiliated with VideoLAN, the original DhakaFlix app, any ISP, PICO, Meta or XREAL. Access only content you are authorized to view.

## Development
GitHub is the primary development and release platform. Android debug APKs are intended to be compiled using GitHub Actions, with device testing required before release.
